
# 🌿 GlowCare – Skincare Landing Page

## About the Project

GlowCare is a modern and responsive skincare product landing page developed as part of the Syntecxhub Front-End Development Internship.

The website introduces a fictional skincare brand and showcases its products through a clean, elegant and user-friendly design.

## Features

- Modern and responsive navigation bar
- Attractive hero section
- About section
- Skincare benefits section
- Product showcase with images
- Contact and call-to-action section
- Smooth scrolling navigation
- Hover effects and transitions
- Responsive design for desktop, tablet and mobile

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries


## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your web browser.
